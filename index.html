        如何免费获取百度 OCR 密钥？（约 5 分钟）
        1. 打开 百度智能云控制台（console.bce.baidu.com），注册并完成个人实名认证；
        2. 搜索「文字识别」→ 选择通用文字识别 → 在「免费资源领取」页领取免费额度（个人认证 1000 次/月）；
        3. 点击「创建应用」，选择文字识别服务，创建后复制页面上显示的 API Key 和 Secret Key；
        4. 把两个 Key 填到上方输入框并保存，即可开始拍照导入单词。
        提示：手机浏览器不能直接调用百度 OCR（跨域限制），请在「转发代理地址」填入云函数转发 URL；填写后手机端无需再填密钥。免费额度 1000 次/月 ≈ 每月可识别 100 张图，个人使用足够。
