# 词刻 · 记忆曲线背单词

手机网页应用（H5 / PWA）：拍单词图片 → 自动识别入库 → 按 SM-2 记忆曲线每天自动安排复习。
纯前端、无服务器，数据全部存在手机本地，全程免费。

> 当前版本：v2.0（阶段二：内置词典 + 关系词引擎 + 日历打卡 + 错词本）

---

## 一、文件清单

| 文件 | 说明 |
|---|---|
| `index.html` | 应用入口（从这里打开） |
| `app.js` | 全部逻辑：数据存储、SM-2 算法、OCR、词典、搜索、复习、统计、备份 |
| `styles.css` | 移动端样式 |
| `dict.js` | **内置词典数据包**（8000 个四六级/考研词：英音音标 + 中文释义；近义词/反义词关系 6679 词），约 1MB |
| `manifest.webmanifest` + `icon.svg` + `sw.js` | PWA 配置（静态托管时支持添加到主屏与离线缓存，含 dict.js） |

部署时把整个「词刻」文件夹里的文件放一起，路径相对关系保持不变即可。

```

```

### 方式 A：发文件到手机（本地离线版，备选）
1. 把 `词刻` 文件夹里的文件打包（或逐个发送）；
2. 通过微信「文件传输助手」发到手机，收到后用**手机自带浏览器**（Chrome / Edge / Safari）打开 `index.html`；

> 注意：安卓系统对本地 `file://` 页面联网跨域限制严格（QQ/夸克等浏览器会拦截本地页面的网络请求，导致 OCR 失败）。**建议优先使用线上地址**；本地版适合纯复习（不识别图片）。

### 方式 B：静态托管（自建网址）
1. 把整个文件夹上传到免费静态托管（GitHub Pages / Gitee Pages）；
2. 手机浏览器访问网址，首次打开后「添加到主屏幕」。

## 三、首次使用：配置 OCR（约 5 分钟）

App 默认用**百度云端 OCR** 识别图片中的单词，推荐通过**百度云函数（CFC）转发代理**调用——密钥只存在云端，手机端只需填一个代理地址，且免费。

### 方式 1：云函数转发代理（推荐，已部署可用，线上版已内置）

线上版（`potter294.github.io/cike/`）的「转发代理地址」已**内置默认值**，无需手动填写；本地 file:// 版如果要用 OCR，请在 App「设置 → OCR 识别引擎」的「转发代理地址」填入并保存：

```
https://ezza9b0gam33p.cfc-execute.bj.baidubce.com/
```

- 该函数在百度 CFC（华北-北京）上运行，入口 `index.handler`，含 CORS 跨域响应头；
- 0 元新客包：前 3 个月每月 100 万次调用免费，之后按量付费（个人使用几乎免费）；
- 手机端只需填代理地址，**不需要**在 App 里填 API Key / Secret Key。

### 方式 2：直连百度 OCR（需要自己的密钥）

1. 打开百度智能云控制台（`console.bce.baidu.com`），注册并完成**个人实名认证**；
2. 搜索「文字识别」→ 选「通用文字识别」→ 在「免费资源领取」页领取免费额度（个人认证 **1000 次/月**）；
3. 点击「创建应用」，复制页面的 **API Key** 和 **Secret Key**；
4. 在 App 的「设置」页填入两个 Key 并保存，即可拍照导入单词。

> 说明：浏览器页面直接调用百度 OCR 会被跨域（CORS）拦截，**手机端请优先填代理地址**（方式 1）；直连模式一般只适合能绕过 CORS 的托管环境。

> 在配置好 Key 之前，可以先使用「手动加词」「词表粘贴导入」体验完整的复习流程。

### 本地 OCR（离线兜底，占位）

「设置 → OCR 识别引擎」提供「本地 Tesseract（离线兜底）」选项，当前为**占位提示**，选择后会提示未安装。
说明：本地 Tesseract 需额外下载约 10MB 组件（tesseract.js + 英文语言包），首次仍需联网，且只能识别英文（图片中的中文释义识别不到），识别质量低于百度云端；个人每月 100 张图的免费额度足够，因此推荐保持云端。后续版本可接入。

## 四、已实现功能（阶段一 + 阶段二）

### 导入与数据
- **图片导入**：拍照/相册选图 → 百度 OCR 自动识别「单词 + 中文释义」
- **人工校对**：识别结果逐条可改、可勾选，一键去重入库
- **手动加词**：输入单词即自动补英音音标与中文释义（来自内置词典）
- **词表粘贴导入**：一次粘贴多行（每行「单词 释义」或仅单词）批量入库

### 复习与记忆
- **SM-2 记忆曲线**：认识 / 模糊 / 忘记 三键反馈，自动计算下次复习间隔（1→6→15→38→94 天…）
- **三种复习模式**：英→中 / 中→英 / 听音拼写
- **发音**：系统 TTS，默认英式发音（可切美式）
- **打卡日历**：统计页按月日历标记复习日，显示连续打卡天数
- **错词本**：答「忘记」自动进错词本；遗忘 ≥2 次标记「难词」；一键强化复习错词

### 词典与扩展
- **内置词典**：8000 个四六级/考研常用词（音标 + 中文释义），本地秒查
- **词典一键加库**：搜索词库外的词时，下方直接给出内置词典命中 + 加入按钮
- **关系词引擎**：详情页展示近义词 / 反义词 / 形近词，点击即加入词库（自动去重、补释义）
  - 近/反义词：内置 WordNet 关系数据 + 可选在线补全（Datamuse，设置页可关）
  - 形近词：本地编辑距离计算
- **中英搜索**：英文前缀/包含 + 中文包含 + 拼写容错 + 搜索历史
- **来源筛选**：词库按「图片导入 / 手动添加 / 关系扩展 / 错词」分组浏览

### 数据与统计
- **统计**：累计词数、今日复习、遗忘率、掌握度分布、近 7 天复习次数
- **备份**：一键导出/导入 JSON，防浏览器清缓存丢词库

## 五、数据来源与许可

- 内置词典数据整理自 **ECDICT**（MIT 许可，`github.com/skywind3000/ECDICT`），筛选四六级/考研标签词并按词频排序；
- 近义词 / 反义词关系提取自 **English WordNet**（`github.com/globalwordnet/english-wordnet`，WordNet License）；
- 在线补全使用 **Datamuse API**（免费，仅查询关系词，失败自动跳过）。

## 六、数据与隐私

- 词库与复习记录存在手机本地浏览器（IndexedDB），**不经过任何服务器**；
- 仅当拍照导入时，图片会发送给百度 OCR 接口做识别（不落服务器）；
- 请定期在「设置 → 导出备份 JSON」保存数据。
